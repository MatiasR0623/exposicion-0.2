# Exposicion: El Mimetismo

Sitio web interactivo para una exposicion sobre el mimetismo.

## Archivos

- `index.html`: pagina principal de la exposicion.
- `intro_mfs_exposicion.mp4`: video de introduccion usado al abrir la pagina.

## Como verlo

Abre `index.html` en el navegador.

El video de intro intenta reproducirse automaticamente con audio. Para repetirlo, haz doble clic en el titulo `El Mimetismo` de la barra superior.

## GitHub Pages

Para publicarlo:

1. Sube todos los archivos de esta carpeta a un repositorio de GitHub.
2. Entra a `Settings > Pages`.
3. En `Build and deployment`, elige `Deploy from a branch`.
4. Selecciona la rama `main` y la carpeta `/root`.
5. Guarda los cambios.
